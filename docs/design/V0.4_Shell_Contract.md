# V0.4 Shell Contract

Phase 0B defines the shared page shell without changing page information
architecture or business behavior.

## Shared shell rules

- `app-content` owns the shared outer gutter: 24px on desktop and 14px below
  the tablet shell breakpoint.
- Every completed page uses a `page-shell` category with `min-width: 0` so
  flex/grid children can shrink within the app content boundary.
- Page-level horizontal overflow is not hidden globally. Wide content must be
  constrained by its page shell or placed in an explicit local scroll region.
- The responsive reference breakpoints are 1100px for wide dashboard reflow,
  820px for tablet navigation/content changes, and 560px for mobile controls.

## Width categories

| Category | Pages | Responsibility |
| --- | --- | --- |
| `portfolio` | Overview | Narrative width, preserving the Hero and section composition. |
| `dashboard` | Budget, Evaluation | Dashboard-wide analysis frame, with page-specific card layouts. |
| `wide` | Salary Analysis | Full available analysis width; chart/structure modules may retain local scroll. |
| `table` | Detail Query | Full available query width; the table owns its horizontal scroll. |

The categories describe the shell boundary; they do not force a shared
`max-width`, card template, module order, or business layout.

## Local scroll boundaries

- Detail's Ant Table remains horizontally scrollable inside its table card and
  keeps fixed columns.
- Evaluation's precision table remains horizontally scrollable inside
  `.evaluation-table-scroll`.
- Salary's position structure region retains its explicit local scroll where
  its wide chart needs it.

No shell rule uses global `overflow-x: hidden` to conceal layout overflow.
