# V0.4 Visual Token Contract

Phase 0A defines the shared visual vocabulary for later V0.4 phases. The
tokens live in `app/design-tokens.css` under the `--ds-*` namespace and are
loaded by the global stylesheet. Defining or loading these variables does not
apply them to existing selectors; page output therefore remains unchanged in
Phase 0A.

## Token groups

- **Color:** page, surface, border, text, primary, accents, semantic status,
  and status-soft backgrounds.
- **Typography:** shared font family, page/section/KPI/body/meta roles, line
  heights, and role weights. Overview's display scale remains a page-specific
  exception.
- **Spacing:** the 4px-based scale from `--ds-space-1` through
  `--ds-space-10`.
- **Shape and elevation:** control/card/section/hero radii, border width, and
  the none/float/hero shadow policy.
- **Control and layout primitives:** control heights, focus ring, content
  category widths, gutters, and breakpoint reference values for later phases.

## Usage and exceptions

Later phases may replace a page-local value only when the change is limited to
visual expression and preserves that page's business structure and interaction.
Budget status colors, Salary category colors, Overview display typography, and
Detail's local-scroll table geometry remain documented page-specific mappings.
No Phase 0A token is a permission to change page selectors, data, calculations,
component order, or scroll behavior.
